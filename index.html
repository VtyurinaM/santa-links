    Как хранятся данные

    Без баз данных и серверов хранения

    Карточки, которые заполняет организатор, живут только в памяти его открытой вкладки. Сайт ничего не пишет ни в базы данных, ни в cookie, ни в память браузера и ничего не отправляет на серверы.

    Что внутри личной ссылки

    Каждая ссылка несёт одно письмо: имя участника-дарителя, имя того, кому он дарит, его пожелания, название комнаты и дату розыгрыша. Письмо зашифровано (AES-GCM), а ключ записан в той же ссылке после знака «#». Эта часть адреса не уходит на сервер GitHub Pages, поэтому письмо видит только тот, у кого есть ссылка.

    Сколько хранятся

    У организатора — пока открыта вкладка комнаты. У участника — пока у него есть ссылка: удалите сообщение со ссылкой, и письма больше нет.

    Кто что видит

    • Участник видит только своё письмо: кому он дарит и пожелания этого человека.
    • Организатор технически может открыть любую ссылку. Чтобы игра осталась тайной для него самого, лучше чужие ссылки не открывать.
    • Кто переслал ссылку дальше, тот раскрыл своё письмо. Отправляйте ссылки только в личные сообщения.

    Чего не стоит писать

    Не указывайте в карточках фамилии, адреса, телефоны и другие данные, которые не нужны для игры. Заполняя карточку за другого человека, сначала спросите его согласия. Аналитики, рекламы и счётчиков на сайте нет, шрифты загружаются с этого же сайта.
