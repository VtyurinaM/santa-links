# Тайный Санта в Нью-Йорке · личные ссылки

Версия сайта, где организатор сам заполняет карточки всех участников, проводит розыгрыш и рассылает каждому личную ссылку. Участникам ничего не нужно регистрировать: открыл ссылку — увидел красивое письмо с именем того, кому дарит.

## Как играть

1. **Организатор** открывает сайт, вводит название комнаты и своё имя и нажимает **«Создать комнату»**. Организатор тоже участвует: сразу откроется его собственное письмо Санте с пожеланиями.
2. Организатор нажимает **«+»** и заполняет карточку на каждого участника: **имя** и **пожелания** (пожелания можно оставить пустыми). Нажав на конверт, карточку можно поправить, крестиком — удалить.
3. Когда все в комнате, организатор нажимает **«Разыграть»**. Конверты перемешиваются, программа выстраивает одну цепочку: каждый дарит ровно одному человеку, каждый получает подарок, никто не дарит сам себе.
4. Появляется список **личных ссылок**. Рядом с каждым именем кнопки **«Скопировать»** и **«Отправить»** (на телефоне открывается меню «Поделиться»). Отправленные ссылки отмечаются зелёным. Своё письмо организатор открывает кнопкой **«Моё письмо»**.
5. **Участник** открывает ссылку и видит красный конверт «Письмо для …». Нажимает — конверт раскрывается, внутри имя того, кому он дарит, и его пожелания.

Для розыгрыша нужно минимум 3 участника, включая организатора.

## Где хранятся данные

- Карточки живут только в открытой вкладке организатора. Закрыл или перезагрузил вкладку — комната стёрлась. **Разошлите ссылки до того, как закроете страницу.**
- Каждая ссылка несёт одно письмо, зашифрованное AES-GCM. Ключ записан в той же ссылке после знака `#`, а эта часть адреса браузер не отправляет на сервер. Поэтому GitHub Pages и кто-либо ещё письма не видят: только тот, у кого есть ссылка.
- Ни баз данных, ни cookie, ни аналитики.

Организатор технически может открыть любую ссылку. Чтобы игра осталась тайной и для него, лучше не открывать чужие ссылки.

## Публикация на GitHub Pages

1. Создайте **публичный** репозиторий на [github.com/new](https://github.com/new), например `santa-links`.
2. **Add file → Upload files** → перетащите все файлы из архива: `index.html`, `404.html`, `.nojekyll`, `README.md` и все шрифты `*.woff2`. Файл `.nojekyll` начинается с точки и может быть скрыт: включите показ скрытых файлов. **Commit changes**.
3. **Settings → Pages** → Source: **Deploy from a branch**, ветка `main`, папка `/ (root)` → **Save**.
4. Через минуту-две сайт откроется по адресу `https://ВАШ-ЛОГИН.github.io/santa-links/`.

## Что внутри

| Файл | Зачем |
